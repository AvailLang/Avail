### Standard library

- The unit-test runner runs tests in different suites concurrently, rather than one suite at a time; a suite with per-test fixtures still runs its own tests, and those of its descendants, one at a time (avail-7i6)
- `left fold_into_through_`, `left fold_through_`, and `right fold_through_` are macros that expand into a loop at each call site, so the fold is typed once at compile time instead of being rechecked on every step (avail-7i6)
- File operations no longer block an interpreter thread while they wait: opening, closing, copying, moving, renaming, truncating, synchronizing, and unlinking files, creating directories, and reading or changing their metadata suspend the calling fiber instead (avail-6s8)
- `Synchronize_with file system` and `Truncate_to_bytes⁇with file system` replace `a fiber synchronizing_with file system,then_else_priority_` and `a fiber truncating_to_bytes⁇then_else_priority_`; `a fiber renaming…` and `a fiber creating a directory named…` are removed in favor of `Rename_to_«(overwrite=_)»` and `Create a directory named_«with file access rights_»` (avail-6s8)
- Socket connects, reads, writes, and accepts suspend the calling fiber; the fiber-returning socket methods are removed, leaving `Connect_to_`, `read«at most»?_byte|bytes from_`, `Write_to_`, and `accept a new connection«named_»on_` (avail-6s8)
- The I/O tests that change a file's contents or access rights work on files of their own, so they run concurrently with one another and with other suites (avail-7i6)

### VM and optimizer

- Idle worker threads wait on a semaphore, and each newly queued or stolen task releases a permit, so a task can no longer sit queued while a worker sleeps (avail-7i6)
- `P_InvokeWithTuple` skips checking an argument that statically conforms to the parameter type of the function's static type, even when the exact function being invoked is unknown (avail-7i6)
- Optimized code decrements a function's reoptimization countdown directly, without a call through the function's descriptor (avail-7i6)

### Internal architecture

- The network library's `Synchronous` modules are merged into the client and server `Primitives` modules, which now hold the blocking socket operations (avail-6s8)
- The `Rational Number` module is removed; its only use was the old range mapping in `_'s⁇next«value in»⁇_` (avail-7i6)
- The descriptor field-write mutability assertion is disabled (avail-7i6)

### Bug fixes

- `_'s⁇next«value in»⁇_` could answer one past the top of the requested range (256 for a byte), and resolved values near a bucket boundary with a bias and without consuming a generator value; it now samples uniformly by rejection, combining enough generator values that retries are rare (avail-7i6)
- The semantic restriction of `right fold_through_` answers the fold's result type rather than the transformer's return type (avail-7i6)
- L2Simple code no longer runs a primitive that can suspend its fiber or invoke a function directly when a primitive function is applied with `invoke_with_` (avail-6s8)
