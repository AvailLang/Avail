### VM and optimizer

- Generated L2 classes have Java-identifier names, `avail.optimizer.jvm.generated.<module>.L<line>_<function>_v<n>.<function>`, with their debug files in a matching directory under `debug/jvm` (avail-50n)
- A Java debugger with `debug/jvm` as a source root steps through generated L2 classes in their L2 listings, which are written as Java sources declaring the class (avail-50n)
- Generated L2 classes name their register locals (`r0`, `i1`, …) for debuggers when JVM debugging is enabled (avail-50n)
- The deep manifest consistency check is off by default

### Build, distribution, and tooling

- The shared IntelliJ run configurations run on JDK 26
